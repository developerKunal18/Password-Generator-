# Password Generator

A simple Python command-line application that generates random secure passwords.

## Features

- Custom password length
- Lowercase letters
- Uppercase letters
- Numbers
- Special characters
- Input validation
- Secure random password generation
- Simple command-line interface

## Technologies

- Python
- secrets
- string
